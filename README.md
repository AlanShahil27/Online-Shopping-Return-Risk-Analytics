# Online Shopping Return Behavior & Return Risk Analytics

## Project Overview

This project analyzes online shopping orders and product returns using Power BI, SQL, and data analysis techniques. The goal is to understand customer purchasing behavior, identify return patterns, and discover factors that may contribute to product returns.

## Objectives

- Analyze total orders, customers, revenue, and product returns.
- Understand customer shopping and return behavior.
- Identify products and categories with higher return rates.
- Analyze revenue trends and return-related business risks.
- Provide actionable insights to improve business performance.

## Tools & Technologies

- **Power BI** – Interactive dashboards and data visualization
- **SQL** – Data querying and analysis
- **Microsoft Excel** – Data inspection and preparation
- **DAX** – Measures and business calculations

## Dashboard Pages

The Power BI report includes four dashboard pages:

1. **Executive Overview** – Key business KPIs and overall performance.
2. **Customer & Order Analysis** – Customer behavior and order patterns.
3. **Return Risk Analysis** – Return trends and factors associated with returns.
4. **Business Insights** – Key findings and recommended actions.

## Project Files

- `Online Shopping Return Behavior & Return Risk Analytics.pbix` – Power BI report
- `online_shopping_returns.zip` – Dataset used for analysis
- `SQL.sql` – SQL queries used in the project
- `Output/` – Dashboard screenshots

## Key Business Questions

- What percentage of orders are returned?
- Which product categories have higher return rates?
- How does customer behavior relate to product returns?
- Which customer or order segments have greater return risk?
- What actions could help reduce returns and improve profitability?

## Business Value

This project demonstrates how data analytics can help an online retail business understand return behavior, investigate potential return risks, and make data-driven decisions.

## How to View the Project

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, locate the dataset and refresh the data.
4. Explore the report pages and interactive visuals.
